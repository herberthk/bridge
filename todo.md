# School Setup

- Join the platform as a normal user then create a school and be the admin of that school, provide all necessary information for the school
- Choose if primary or secondary school
- Create classes of the school, depending on primary or secondary school (e.g., primary school has classes primary 1 to 7 and secondary school has classes secondary 1 to 4 for Ordinary level, secondary 5 to 6 for advanced level)
- Create a teacher and invite them to the school; on accepting the invite the teacher should be able to login and see the school in their dashboard, and assign the classes to manage
- Create a dashboard for each teacher and classes
- Let the admin or teacher create or add students to the school or class
- Schools will have a blue tick if they are verified by the super admin
- Let the admin or teacher manage or see all the students and teachers assigned to their school

# Exam generation

- The teacher or admin should be able to generate exam or test in class dashboard and invite students to take the exam
- There should be a leaderboard for performance tracking for each class
- The admin or teacher should be able to see the result of the students and the overall performance of the class
- The admin or teacher should have option to allow students to reattempt the exam
- During examination generation, the teacher or admin should have option to set a deadline or expiry date and time for the exam
